# 需求追踪与验收边界

| 需求 | 实现入口 | 自动验证 |
|---|---|---|
| UC-01 仪器检索与可用时段查询 | 仪器资源、日期时段API | 日期窗口/粒度、检索浏览器测试 |
| UC-02 预约申请 | 三步表单、草稿增改删、提交 | 主流程、资质信用、参数、草稿与历史 |
| UC-03 预约审批 | 工作台、批准/理由驳回 | 跨机组越权、重复状态、浏览器审批 |
| UC-04 时段冲突校验与候补排队 | 半小时占用约束、事务、补位确认 | 100/500并发、部分重叠、FIFO、确认超时 |
| UC-05 扫码上机签到 | 网页编号核验、wx.scanCode | 时间窗、身份归属、错仪器、重复签到 |
| UC-06 使用计时与费用结算 | 下机、价格快照、核销、冲正、CSV | 内外价格、金额精度、重复结算、冲正 |
| UC-07 检测结果交付 | 报告上传、加密存储、授权下载 | 文件格式、越权、加密、SHA-256完整性 |
| UC-08 培训与上机资质认证 | 报名初审、课程、考试、撤销 | 未初审阻断、成绩、发证、撤销、到期提醒 |
| UC-09 违约认定与信用分管理 | NoShow/超时/损坏、申诉复核 | 幂等扣分、权限、恢复一次、阈值 |
| UC-10 设备维保与停用 | 即时和计划维保、取消与恢复 | 免罚取消、时段隔离、使用中保护 |
| UC-11 开放共享绩效报表 | 三种口径、ECharts、CSV | 阈值、机时与维保分母、20万数据、浏览器导出 |
| UC-12 消息通知 | 站内信、提醒、投递队列 | 归属、已读、提醒幂等、远端失败重试 |
| UC-13 仪器台账管理 | 建档编辑、JSON导入、外部同步 | 导入事务、编号去重、只读来源 |

## 当前边界

- 本地验证使用H2；生产MySQL/Redis/MinIO编排已提供，但本机Docker引擎未就绪，三重保护的Redis分支和MinIO实际网络服务不能以本地测试代替验收。
- 统一认证和消息网关有自动契约测试，真实学校/微信/财务系统未联调。
- 原生小程序源码具备业务入口，正式AppID、真机兼容性、微信发布和订阅绑定待部署环境验收。
- 报告上传限制20MB，未实现分片上传和敏感报告分级审批；超过上限的原始数据需在后续扩展中接入分片。
- 报表提供仪器明细及机组/院系字段，当前没有独立的机组/院系聚合视图、预聚合任务和异步报表档案。
- 当前统计门槛按三个固定阈值实现；是否“列入校内清单”而不满足金额阈值的例外规则尚无配置界面。
- 候补按独立提交序号排序，Redis只承担生产锁；Redis候补队列和乐观锁降级重试与SRS存在实现差异。
- 结算修正有历史记录；完整的经费卡目录、实名附件上传和个人信息注销工作流尚待机构规则确定。
- 等保二级、年度可用率、真实备份恢复时长、百万历史容量、用户易用性走查均需独立验收证据。

本文件明确记录已实现内容与差异，不把课程演示系统描述为已经完成全部生产验收。
