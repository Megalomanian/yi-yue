# 使用说明

## 送样人

登录 student 或经审核的校外账号。在“仪器资源”按名称、型号、编号和分类检索。点击“查看机时”，依次选择日期与时段、填写样品/联系人/结算信息、确认提交，共三步。空闲时段进入待审批，已占用时段进入候补。可以保存草稿并在“我的预约”编辑、删除或提交。

收到批准通知后，到机位使用小程序扫码签到；网页可输入机位编号，由后端核验归属和时间窗。开始后15分钟未签到会扣20分；超时占用15分钟扣10分。结束时联系机组负责人确认下机结算，系统按实际时间计费。

候补补位后必须在通知给出的期限内确认，超时会自动顺延。待审批不能自行撤回，联系机组驳回；已批准和候补可以取消；使用中须先结算。

“结算与报告”查看费用、核销状态和机组上传的文件。下载仅限本人和授权机组。资料以加密形式保存，后端校验完整性后交付。

“培训与资质”先报名、等待初审、学习课程，再参加5题考试。达到80分获得一年资质；未通过可补考。资质撤销后需重新初审，不能直接考试绕过撤销。

“信用与申诉”查看违约流水并提交事实依据；管理员复核成立后恢复分数。同一违约不会重复扣分或重复恢复。

## 仪器负责人

登录 manager。“预约工作台”只展示所属机组数据，核对样品与申请人信用后批准或填写理由驳回。可代用户核验签到，使用结束后执行“下机结算”。

在“结算与报告”上传PDF/CSV/TXT/ZIP文件，最大20MB；在线完成费用线下核销；金额纠错通过“冲正”保留原始账单。

“设备维保”支持立即停用或设置计划起止时间。冲突预约免违约取消并通知改约；使用中的预约需先结束。计划时段到达后自动停用，到期恢复；提前完成可手动恢复。

## 管理员与主管部门

管理员通过“仪器建档”录入编号、名称、型号、分类、位置、机组、资产价值、内外价格和开放小时。批量导入使用JSON数组，字段与建档表单对应，例如：

```json
[{"code":"IY-NEW-01","name":"示例仪器","model":"Model A","category":"光谱分析","location":"A101","department":"示例机组","group_id":1,"price":100,"external_price":200,"asset_value":500000,"open_hour":8,"close_hour":18}]
```

外部台账由同步接口维护，本地表单不可修改。相同编号同步去重，外部编号与本地台账冲突时要求人工核对。

在“用户审核”查看校外核验材料并审核；在“培训与资质”撤销失效资格；在“信用与申诉”复核扣分或登记已核实设备损坏；在“操作审计”查看变更留痕。

管理员和 department 均可在“绩效报表”选择国家/地方/校内口径、日期周期并生成或导出CSV。财务CSV包含费用单、卡号/对公信息、项目、机时和核销状态，应按机构权限保管。

## 微信客户端

微信开发者工具导入 `miniprogram/`。本地开发可使用测试AppID；正式发布须设置真实AppID、HTTPS request/download合法域名，并将 `app.js` 中 `baseUrl` 改为服务地址。真机的127.0.0.1指向手机自身，不能直接访问电脑上的本地后端。

机位二维码内容可以为数字仪器ID，或 `instrument_id=1`。原生客户端通过 `wx.scanCode` 读取。二维码打印与真机扫码在正式环境验收。

网页移动界面使用Vant底部导航；原生小程序使用微信原生组件。SRS把Vant/Vue和原生小程序混写，当前采用两套客户端共用同一后端的实现方式。
