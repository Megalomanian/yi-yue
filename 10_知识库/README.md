# 仪约（InstrumentHub）项目知识库

> **项目全称**：高校大型仪器设备开放共享预约平台（代号：`IY`）
> **仓库定位**：集「事实源核验 → 开题与需求工程 → 答辩材料 → 全栈可运行系统（Spring Boot + Vue 3 + 微信小程序）→ 自动化测试与发布」于一体的软件工程全生命周期仓库。

本知识库将分散在需求文档、核验报告、答辩讲稿、前后端源码、数据库迁移脚本与测试报告中的信息进行结构化收敛，供**课程终期验收、组员协同开发、新成员交接与 AI 辅助演进**统一查阅。

## 四、事实优先级约定（冲突裁决准则）

当不同阶段产物出现细节出入时，按以下优先级裁决：

1. **系统已实现行为与数据库/接口契约**：以 `system/backend/src/main/` 与 `system/backend/src/main/resources/db/migration/` 源码及 `system/docs/TEST-REPORT.md` 实测结果为准。
2. **需求基线、编号体系与文档合规红线**：以 [../00_事实源/project-card.md](../00_事实源/project-card.md) 为唯一事实来源（SST）。
3. **阶段演进差异**：M1/M2 文档（如 [../09_答辩稿/00_总答辩稿-需求评审.md](../09_答辩稿/00_总答辩稿-需求评审.md)）中部分早期设想在 M4/M5 编码阶段做了工程化收敛，所有差异均已在 [02_业务规则与状态机详解.md](./02_业务规则与状态机详解.md) 与 [05_需求追踪与验收边界矩阵.md](./05_需求追踪与验收边界矩阵.md) 中显式列出。
