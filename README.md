# 仪约 InstrumentHub

**高校大型仪器设备开放共享预约平台** —— 把分散在即时通讯群、Excel 台账与纸质上机本中的仪器预约方式，收敛为**在线查机时、在线约机时、扫码上机自动计时、按机时自动结算、多口径一键导出考核报表**的一体化平台。

> 宁夏大学信息工程学院 · 软件工程课程设计第 3 组（指导教师：曾升）
> 成员：朱林立（组长）、张雨欣、张义、秦嘉玉、孙福泽、许军 ｜ 用户单位：宁夏大学测试分析中心

## 一、核心特性与工程亮点

- **全链路 9 状态预约闭环**：支持 14 天半小时粒度排期、三步预约与草稿保存、机组审批/驳回、按提交受理顺序（`submission_sequence`）自动候补递补与限时确认、15 分钟窗口扫码签到、秒级 `BigDecimal` 精确结算与不可篡改冲正流水。
- **四层并发防超卖机制**：生产 Redis Lua 令牌互斥锁 + 数据库仪器行级悲观锁（`FOR UPDATE`）+ 预约 `version` 乐观锁 + `slot_claim(instrument_id, slot_at)` 复合主键兜底，500 并发抢约实测 **0 超卖**。
- **国家 / 地方 / 校内三套口径同源统计**：围绕 50 万元、20 万元、40 万元三级资产门槛实时切换统计口径，自动扣减维保停机分母，支持 ECharts 可视化与防公式注入 CSV 一键导出（500 台仪器、20 万预约单基线聚合耗时 `3.96 s`）。
- **培训—初审—考核—准入安全链**：报名经机组初审后参加在线安全考核（≥80 分颁发 1 年期上机资质），支持提前 30 天到期提醒与违规撤销重审闭环。
- **端到端密码学保护与审计**：密码 `BCrypt` 哈希，联系方式、经费卡号、校外实名材料及检测报告全程采用 `AES-256-GCM` 加密存储，报告下载强制校验明文 `SHA-256` 摘要，全关键行为记录安全审计日志。
- **多端协同与平滑外部对接**：内置 Vue 3 桌面管理端、移动响应式 Web 与原生微信小程序（`wx.scanCode` 现场扫码），并通过事务外发箱（Outbox）预留统一身份认证（SSO）、微信模板消息与既有平台台账/结算网关。

## 二、快速启动（本地演示）

前置环境：JDK 21、Maven 3.9、Node.js 22/24、Chrome（或 Edge）。

```powershell
cd system
./scripts/build.ps1   # 后端测试、JaCoCo 覆盖率与打包；前端单测与生产构建
./scripts/start.ps1   # 后台启动前后端并通过健康检查
```

- **Web 平台入口**：<http://localhost:5173>
- **Swagger UI 接口文档**：<http://localhost:8080/swagger-ui/index.html>
- **停止服务**：`./scripts/stop.ps1`（安全停止进程，不清除本地演示数据）
- **预置演示账号**（密码统一为 `Demo12345!`）：
  - `student` / `student2`（校内送样人） · `external`（已审核校外用户）
  - `manager` / `manager2`（第 1 / 第 2 机组负责人）
  - `admin`（平台管理员） · `department`（主管部门只读报表与财务导出）

打包发布产物（含预构建可运行包）可在 [GitHub Releases v1.0.0](https://github.com/Megalomanian/yi-yue/releases/tag/v1.0.0) 下载。
