## 三、改稿流程

```powershell
# 改正文：编辑 01_开题报告/开题报告-正文.md 或 03_SRS/SRS-正文.md
python 06_构建脚本/md2docx.py
powershell -File 06_构建脚本/docx2pdf.ps1 -Docx "01_开题报告/项目开题报告.docx" -Pdf "07_交付/项目开题报告.pdf"

# 改 PPT
python 06_构建脚本/build_ppt.py
powershell -File 06_构建脚本/pptx2pdf.ps1 -In "02_答辩PPT/开题答辩.pptx" -Out "07_交付/开题答辩.pdf"

# 改完重跑自检
python 06_构建脚本/qa.py
```

- 正文里 `[[FIG:图x-x]]` 是图片占位符，**不要删**；紧随其后的那一行是图题，改这行即可。
- 封面信息、变更历史记录在 `06_构建脚本/md2docx.py` 顶部的 `KT` / `SRS` 字典里，改完重跑。
