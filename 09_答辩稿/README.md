## 二、两份稿子怎么配合用

- **总稿**是给评审会用的：15 分钟讲述 + 10 分钟问答，按「开场与进度 → 需求从哪来 → 需求模型 → 非功能 → 界面原型 → 数据契约 → 部署交付 → 提请确认的 5 个问题 → 下一步」的顺序推进，末尾 20 个问题按 A 类（需求与方法）、B 类（业务与规则）、C 类（技术可行性）、D 类（项目管理）分组，并注明了谁答。
- **个人稿**是给每个人自己背的：只讲自己那摊，附 10 个「问到你头上」的问题，最后有兜底话术。
- 两份稿子的事实完全一致，都来自 `00_事实源/project-card.md`。

## 三、四个提醒

1. **总稿第 2 节主动交代了"没做一手访谈和问卷"**，这是设计好的，不要临场回避——主动说明方法选择的理由，比被问出来强得多。
2. **第 8 节的 5 个问题是真的想听意见**，念的时候要有停顿，别一口气读完。
3. 被问到不属于自己的部分，按第 11.1 节的分工把话筒递出去，别硬答。
4. 兜底话术第 3 条（"您说得对，这一处我们回去改"）要用得干脆，不要辩解。
